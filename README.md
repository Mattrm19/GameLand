# 🎮 GameLand — Tienda de Videojuegos

**GameLand** es una tienda digital de videojuegos desarrollada como proyecto web utilizando **HTML, CSS y JavaScript con React**. La página cuenta con una interfaz moderna orientada al mundo gaming y permite simular el proceso de navegación, selección de productos, carrito de compras, inicio de sesión y pago.

## 📖 Descripción

GameLand es una tienda virtual donde los usuarios pueden explorar un catálogo de videojuegos de diferentes plataformas, consultar ofertas y próximos lanzamientos, agregar productos al carrito y realizar una simulación de compra.

El proyecto fue desarrollado con el objetivo de aplicar conocimientos de **desarrollo web mediante el uso de metodologías no code**.

## ✨ Funcionalidades

### 🏠 Página de inicio

* Carrusel automático de contenido.
* Ofertas destacadas.
* Sección de próximos lanzamientos.
* Preguntas frecuentes.
* Información de contacto.

### 🎮 Catálogo de videojuegos

El catálogo cuenta con juegos de diferentes plataformas:

* Nintendo Switch
* PlayStation
* Xbox
* Steam

También incluye filtros para mostrar los videojuegos de cada plataforma.

### 🛒 Carrito de compras

* Agregar videojuegos al carrito.
* Aumentar o disminuir cantidades.
* Eliminar productos.
* Visualizar el subtotal.
* Calcular el total de la compra.
* Acceder al proceso de pago.

### 👤 Cuenta de usuario

* Inicio de sesión.
* Validación de nombre de usuario.
* Validación de correo electrónico.
* Validación de contraseña.
* Visualización de información de la cuenta.
* Cierre de sesión.

### 💳 Pago simulado

La página incluye un formulario de pago que permite introducir:

* Número de tarjeta.
* Fecha de vencimiento.
* CVV.
* Nombre del titular.

El pago es **únicamente una simulación con fines académicos** y no realiza transacciones reales.

### 📦 Historial de compras

Después de realizar una compra simulada, los productos aparecen en la sección **"Mis compras y seguimiento"**, junto con:

* Número de orden.
* Fecha de compra.
* Estado del pedido.

## 🚀 Ejecutar el proyecto

No es necesario instalar Node.js, npm ni configurar un servidor para utilizar el proyecto.

### Opción 1 — Abrir localmente

1. Descargar el repositorio.
2. Abrir el archivo `index.html`.
3. Ejecutarlo utilizando un navegador web moderno.

### Opción 2 — GitHub Pages

El proyecto puede publicarse mediante **GitHub Pages**, permitiendo acceder a la tienda desde un navegador mediante una URL pública.

## ⚠️ Consideraciones

Este proyecto es una **demostración académica**.

El sistema de inicio de sesión, carrito, pedidos y pago funciona únicamente en el navegador mediante el estado de React.

**No existe un backend ni una base de datos**, por lo que:

* Las cuentas no se almacenan permanentemente.
* Las compras no son reales.
* Los pagos no procesan tarjetas reales.
* Los datos se pierden al recargar la página.
* No se deben introducir datos reales de tarjetas.

Las imágenes de los videojuegos se cargan desde fuentes externas mediante sus respectivas URLs.
